# baton-role-frontend-dev

Enabling this plugin makes this machine's Claude Code the Baton **frontend-dev** agent: its `settings.json` activates the `frontend-dev` agent as the main thread, with that agent's tools, model and instructions. It depends on `baton-core` for the MCP server, the gates and the protocol skill.

Install: `/plugin install baton-role-frontend-dev@clane-ai`. Regenerated from `packages/cli/roles/frontend-dev.md` by `node plugins/gen-role-plugins.mjs`; edit the role there.
