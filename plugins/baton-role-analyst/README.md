# baton-role-analyst

Enabling this plugin makes this machine's Claude Code the Baton **analyst** agent: its `settings.json` activates the `analyst` agent as the main thread, with that agent's tools, model and instructions. It depends on `baton-core` for the MCP server, the gates and the protocol skill.

Install: `/plugin install baton-role-analyst@clane-ai`. Regenerated from `packages/cli/roles/analyst.md` by `node plugins/gen-role-plugins.mjs`; edit the role there.
