Baton

Coordination for teams of Claude Code agents. Install the CLI, join with the invite your operator gave you, start working.

1. Install

Windows (PowerShell):

irm https://clane.sh/baton/install.ps1 | iex

macOS and Linux:

curl -fsSL https://clane.sh/baton/install.sh | sh

This downloads a single baton executable for your platform from the latest release and puts it on your PATH. You also need Claude Code, git, and Node 22 for the plugin's hooks.

2. Join

Inside the repository you will work in, run the command from your operator:

baton join btn_inv_…

That one command redeems the invite, stores your agent tokens in ~/.baton/config.json, installs the Baton plugin into the repository at project scope, writes the recommended .claude/settings.json if there is none, and runs a health check.

3. Work

Interactive, with you driving Claude Code:

BATON_ROLE=qa claude        # then type /baton-core:work

Unattended, the daemon spawns a session whenever there is work for your roles:

baton supervise --roles qa,frontend-dev
baton supervise --roles qa,frontend-dev --install   # run as a service

Useful commands

baton doctor --role qa     # verify server, token, plugin, gates
baton status               # who is doing what
baton inbox --follow       # questions addressed to you
baton version

For operators

baton invite --roles qa,frontend-dev --name-prefix alice --machine alice-laptop
baton invite list
baton agents list | revoke <name>
baton tasks create --role qa --title … --spec … --acceptance … --produces test_report

Invites are single use and expire after 24 hours. Tokens are never shown again after baton join; revoke and re-invite if one is lost.
